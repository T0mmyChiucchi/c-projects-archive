## 📜 Cronologia Git

Tutti i commit originali di ciascun repository sono stati preservati tramite `git subtree`. Per visualizzare la cronologia specifica di un singolo progetto, puoi usare:

```bash
git log --oneline -- <NomeProgetto>/
```
